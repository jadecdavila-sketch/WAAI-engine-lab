# WAAI Member App — Concept Prototype

A design prototype of an AI-native member app for Women Applying AI.
All member data is fictional. AI features show saved examples in this
hosted version; the live AI experience runs in the Claude demo.

Prototype by Jade Davila.

## Deploying to GitHub Pages

1. Create a new repository at github.com/new (public repo for free
   GitHub Pages). Name it anything, e.g. waai-member-app.
2. Upload everything in this folder (index.html, the assets folder,
   and this README) to the repository root. The "uploading an existing
   file" link on the empty-repo page works fine; drag them all in and
   commit.
3. In the repository: Settings, then Pages. Under "Build and
   deployment" choose Source: Deploy from a branch, Branch: main,
   Folder: / (root). Save.
4. Wait a minute or two. Your app will be live at:
   https://YOUR-USERNAME.github.io/waai-member-app/

To update later, replace the files and commit; Pages redeploys
automatically.
